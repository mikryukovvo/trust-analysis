# Анализ доверия к органам власти

Репозиторий содержит материалы апробации методологии анализа доверия к органам власти на основе текстовых данных.

Пилот выполнен на массиве публичных русскоязычных текстов и предназначен для проверки работоспособности методологического подхода.

Результаты демонстрируют возможность предложенного подхода и задают направление дальнейшей проверки на больших и репрезентативных массивах данных.
