# Анализ доверия к органам власти

Репозиторий содержит материалы апробации методологии анализа доверия к органам власти на основе текстовых данных.

## Заявление о доступности данных (Data Availability Statement)
В соответствии с Федеральным законом РФ № 152-ФЗ "О персональных данных" и этическими стандартами исследований цифровых следов, полный исходный датасет (n = 15 020 единиц контента), собранный методом парсинга, автор пока не раскрывает по причине того, что готовится к защите диссертации.
Представленный здесь репозиторий содержит **структурно идентичный, полностью анонимизированный поднабор данных** (`manual_texts.csv`, n=4500, ~30% от общего объема). Этот набор предназначен исключительно для **демонстрации воспроизводимости пайплайна**. Он позволяе запустить предоставленный код, проверить логику предобработки, обучения модели и расчёта метрик, получая сопоставимые результаты.

## Структура репозитория
- `data_dictionary.csv` – описание структуры данных и кодировки переменных (5 классов доверия).
- `manual_texts.csv` – анонимизированный поднабор данных для проверки кода.
- `01_preprocessing.py` – скрипт очистки данных (дедупликация MinHash, фильтрация ботов).
- `02_finetune.py` – скрипт тонкой настройки модели ruRoBERTa-large.
- `03_shap_analysis.py` – скрипт расчёта вкладов признаков.


Набор данных выполнен на массиве публичных русскоязычных текстов и предназначен для проверки работоспособности методологического подхода.
